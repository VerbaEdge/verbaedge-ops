# VerbaEdge operations service scope

1. **Discover**: workflow inventory, asset criticality, regulatory/credential register, exception logs.
2. **Operate**: intake, dispatch planning, PM scheduling, warehouse/facility work and fleet-readiness documentation.
3. **Integrate**: CMMS-style original schema, partner-authorized API, data provenance and management reporting.
4. **Improve**: maintenance backlog, response times, preventive compliance, failure analyses and control reviews.
5. **TradeFlow**: handoff and document readiness for shipments, border-port references, invoice/PO matching and exceptional-event audit.

## Services to develop in phases
| Phase | In-house digital/workflow service | Actual regulated physical service |
|---|---|---|
| Phase A | Asset register, PM plan, work order intake, procedures review | No physical repairs claimed |
| Phase B | Vendor scope and partner onboarding, mobile checklists | Only verified licensed providers where required |
| Phase C | Facilities service coordination, fleet inspections planning | Contractor approvals, insurance and site safety required |
| Phase D | OT/IIoT integrations, real-time dashboards, preventive analytics | Only with customer permission and controlled engineering scope |
| Phase E | Freight document and milestone tracking | Separate FMCSA/CBP registrations or licensed partners before regulated activities |

## Non-claims
No statement that VerbaEdge has performed the services, owns trucks, has registered broker authority, employs technicians, provides live GPS, holds customs licences or meets compliance standards without documentary evidence.
