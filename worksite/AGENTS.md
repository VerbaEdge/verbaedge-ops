- Keep VerbaEdge Systems LLC as the sole legal entity unless owners approve a new entity.
- Do not invent licences, carrier authority, clients, office addresses, certifications, live shipment events, or success metrics.
- Preserve dark navy/blue/teal and the Inter/system font stack from the supplied VerbaEdge source.
- Build static-first for Cloudflare Pages. Use only dependencies deliberately reviewed by the owner.
- Prioritize WCAG accessibility, mobile-first layouts, security, keyboard support, and no surprise personal-data collection.
- Commit code on branches, run `npm test && npm run build` and document verified outcomes.
- No deployment to production without explicit owner authorization.
- Use only rights-cleared imagery. Remote Unsplash image links need final per-photo check.
- Do not copy Intelloop's ADAPT names or Atlas CMMS source, screenshots or trademarked design.
- Keep Xernavia legally and operationally separate from this project.
